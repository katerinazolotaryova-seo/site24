Как читать это досье — и чего в нём нет

В этой сессии WebFetch и прямой curl снова полностью заблокированы egress-прокси (проверено на inweb.ua — EGRESS_BLOCKED). Доступен только WebSearch — он даёт заголовки страниц (обычно совпадают с реальным <title>) и сжатые пересказы контента, но не даёт дословный meta description, точный порядок H1/H2, число слов и частотность фраз — это требует чтения сырого HTML.

  • ✓ надёжно — заголовки страниц, URL-структура, партнёрства/сертификаты, кейсы с именами, годы на рынке — подтверждены минимум одним прямым упоминанием.
  • ~ приблизительно — цифры расходятся между источниками (разные годы основания, разная численность штата) или взяты из вторичных каталогов.
  • ✕ нужен HTML — meta description дословно, порядок блоков, число слов, топ-10 фраз по частотности — по всем 14 доменам без исключения.

Чтобы закрыть ✕-пункты: пришлите HTML пяти основных пар страниц (SEO+PPC у inweb.ua, locomotive.ua, penguin-team.ua + главные sprava.ua и luxeo.team) через Ctrl+U → «Сохранить как», либо прогоните все 14 доменов через Screaming Frog, как ранее с vizy.ua — краулер отдаст title/description/H-теги/word count по всем страницам разом.

Важная поправка к брифу

  • При поиске «luxeo.team PPC» систематически всплывает другой домен — luxeo.com.ua: украиноязычное агентство контекстной рекламы (Google Ads, Яндекс.Директ), не связанное по контенту с luxeo.team. На странице контактов luxeo.team действительно указаны оба адреса (order@luxeo.team и partner@luxeo.com.ua) — это может быть один холдинг с двумя брендами под разные рынки, а может быть совпадение названия. Разница принципиальна: если это разные компании, luxeo.team вообще не локальный конкурент site24 по PPC и слабый конкурент по SEO (другой язык, другая аудитория — IT/SaaS-аутсорс, а не украинский SMB). Стоит выяснить у Google/через WHOIS или прямым письмом, прежде чем считать luxeo.team полноценным конкурентом по обеим услугам.

«Только гео-лендинги» — не редкость

sprava.ua, ideadigital.agency (для PPC) и, вероятно, limenet.kiev.ua (для SEO) не имеют единой обобщённой страницы услуги — работают через город/нишу. Если у этих запросов есть объём без геопривязки, это ниша, которую сейчас никто из них не закрывает напрямую.

06 — методология

Что нельзя было проверить и как это закрыть

Пробелы, общие для всех 14 доменов

  • Meta description дословно — WebSearch отдаёт пересказ, а не сырой тег.
  • Порядок блоков страницы (хиро → кейсы → отзывы → FAQ → цены → форма) — не виден по сниппетам ни для одного домена.
  • Число слов основного текста — требует загрузки HTML и подсчёта после исключения меню/футера.
  • Топ-8–10 фраз по частотности — то же самое, нужен полный текст страницы.
  • Именные авторы/эксперты на страницах услуг — не всплывают в SERP-сниппетах, даже если реально есть на сайте.

Два рабочих способа закрыть всё сразу: (1) прислать HTML пяти-семи приоритетных страниц через Ctrl+U → «Сохранить как» / вставить код; (2) прогнать все 14 доменов через Screaming Frog одним крауом, как ранее делали для vizy.ua — на выходе получите title/description/H1–H2/word count по каждой странице без ручной пересылки.
