# Базовый SEO-анализ конкурентов (presale)

Это воркфлоу для быстрого, но обоснованного цифрами конкурентного анализа
перед подготовкой коммерческого предложения. Он собирает данные через
DataForSEO вместо того, чтобы гадать по общему поиску — обычный
веб-поиск даёт не локализованную, не гео-таргетированную выдачу и не
годится для реального SERP-снимка (сайты меняются местами, появляются
доноры из чужой страны и т.д.). Если у пользователя нет доступа к
DataForSEO — прямо скажи, что нужен настоящий SERP-инструмент, и предложи
варианты (см. раздел "Если DataForSEO недоступен" ниже), а не выдавай
результаты обычного веб-поиска за топ-10.

Пройди четыре шага по порядку. Каждый шаг — это отдельное решение
пользователя, поэтому после каждого шага естественно остановиться и
показать промежуточный результат, а не сразу гнать до конца — но если
пользователь явно попросил "сделай всё", можно пройти все шаги подряд.

## Перед началом: учётные данные DataForSEO

Все скрипты читают `DATAFORSEO_LOGIN` и `DATAFORSEO_PASSWORD` из
переменных окружения. Если их нет — спроси у пользователя логин
(обычно email) и пароль (API-ключ) от DataForSEO и экспортируй их:

```bash
export DATAFORSEO_LOGIN='user@example.com'
export DATAFORSEO_PASSWORD='xxxxxxxxxxxxxxxx'
```

**Никогда не записывай реальные логин/пароль в файлы, коммиты, скрипты
или куда-либо ещё, что может попасть в git или в сам скилл.** Они живут
только в переменных окружения текущей сессии.

Некоторые тарифы DataForSEO принимают только один task за раз в
Live/Advanced-запросах ("You can set only one task at a time") — все
скрипты в этом скилле уже учитывают это и шлют по одному task на запрос,
поэтому большой список запросов/доменов означает много последовательных
вызовов, а не один быстрый батч. Это нормально, просто требует времени.

## Шаг 1 — Топ-10 выдача по ключевым запросам

Собери у пользователя список запросов (обычно 3-10 фраз, которые реально
ищут покупатели: "купить X", "купити Y" и т.п.). Уточни локацию, если она
не очевидна из контекста (страна/регион сайта), и не бойся смешивать
языки в одном списке (ru/uk и т.п. — это нормально для рынков вроде
Украины).

```bash
python3 scripts/serp_top10.py --input queries.txt --location "Ukraine" --out serp_results.json
```

`queries.txt` — одна фраза на строку, опционально с `|язык`:
```
купить мотор BMW|ru
купити двигун Mercedes|uk
```

Покажи пользователю топ-10 по каждому запросу и посчитай, сколько раз
встретился каждый домен по всем запросам сразу — это самый быстрый способ
увидеть, кто реально доминирует в нише. Малые агрегаторы вроде OLX/Prom и
их аналоги в других странах почти всегда лезут в топ по любому товарному
запросу — не считай их автоматически "конкурентами" в смысле presale,
но и не убирай молча: спроси пользователя, интересны ли ему маркетплейсы
такого рода, или он хочет сравнение только с профильными магазинами.

## Шаг 2 — Кто эти конкуренты на самом деле

Название домена ничего не говорит о том, чем магазин правда торгует —
"euromotors.com.ua" может продавать не только моторы, а
"zapchastie.in.ua" (общее "запчасти") — оказаться узким специалистом по
двигателям. Проверять это через прямой заход на сайт обычно не работает —
в песочнице агент часто блокирует произвольный исходящий трафик к
незнакомым доменам (WebFetch будет падать с `EGRESS_BLOCKED`). Вместо
этого используй сами данные DataForSEO: по каким ключевым словам домен
реально ранжируется, красноречивее любого меню сайта.

```bash
python3 scripts/ranked_keywords.py --domains domains.txt --location "Ukraine" --language ru --out ranked_keywords.json
```

Затем **прочитай список ключевых слов сам** и сделай вывод:
- Почти все ключи — коды/модели одного типа товара (например коды
  двигателей) → узкий специалист.
- Ключи покрывают явно разные категории (диски, фары, бамперы, АКПП и
  т.д.) → магазин с полным ассортиментом, где искомый товар — лишь одна
  из категорий.
- Ключи вообще не о том (например мотошлемы среди автозапчастей, или
  случайные несвязанные товары) → это, вероятно, не настоящий конкурент —
  предложи пользователю исключить домен и объясни почему.

Зафиксируй результат этой классификации простым списком (сохрани как
`classification.json`, формат описан в docstring `build_report.py`) —
это ручное суждение, а не то, что можно снова получить автоматическим
вызовом API, так что не теряй его.

Явно проговори с пользователем финальный список конкурентов и что
исключено — это отдельное решение, которое стоит зафиксировать в чате
("зафиксируй как согласование списка конкурентов"), прежде чем считать
по нему деньги и трафик на следующем шаге.

## Шаг 3 — Масштаб SEO у каждого конкурента

Для согласованного в шаге 2 списка доменов (плюс сам сайт клиента —
он всегда должен быть в таблице для сравнения) собери четыре метрики:

```bash
python3 scripts/domain_metrics.py --domains final_domains.txt --location "Ukraine" --language ru --out metrics.json
```

Это даёт: страниц в индексе (через Relevant Pages — не пытайся получить
это через `site:domain`, Google больше не отдаёт по этому запросу
надёжную оценку), домены-доноры (Backlinks Summary), ключевые слова и
SEO-трафик/мес (Domain Rank Overview; трафик — это `organic.etv`, оценка
визитов, а не денежный эквивалент — тот отдельно называется
`estimated_paid_traffic_cost`).

## Шаг 4 — Собрать всё в один файл

```bash
python3 scripts/build_report.py \
    --serp serp_results.json \
    --classification classification.json \
    --metrics metrics.json \
    --client motors.com.ua \
    --out seo_presale.xlsx
```

Все три входа, кроме `--metrics`/`--client`/`--out`, опциональны — передавай
только то, что реально собрал. Строку клиента скрипт подсветит
автоматически, исключённые в classification.json домены (категория с
пометкой "ВИКЛЮЧЕНО") на лист метрик не попадут.

**Про формулы в этом файле**: сводные строки (среднее/максимум по
конкурентам) пишутся как готовые посчитанные числа, а не как живые
формулы `=AVERAGE()`. Это осознанный компромисс: обычный workflow для
Excel-файлов требует прогнать файл через LibreOffice-пересчёт после
записи формул (иначе никто — ни pandas, ни предпросмотр — не увидит
значения), но в этой песочнице headless LibreOffice надёжно зависал на
400+ секунд даже на паре простых формул. Если работаешь в среде, где
`soffice` отвечает нормально — можно смело заменить эти строки на живые
формулы, просто не забудь прогнать `recalc.py` из скилла `xlsx` после и
дождаться, что он реально завершится, а не считать долгое ожидание
нормой.

Отправь готовый xlsx пользователю (`SendUserFile`, если доступен).

## Если DataForSEO недоступен

Не выдавай результаты обычного веб-поиска (WebSearch и т.п.) за топ-10
выдачу — это, как правило, не гео-таргетированный и не локализованный
результат, и он вводит в заблуждение при подготовке presale-материалов
для клиента. Вместо этого честно скажи пользователю, что нужен SERP/
SEO-инструмент (DataForSEO, Serpstat, Ahrefs, SE Ranking, Keys.so и
т.п.), и либо попроси доступ, либо предложи собрать данные вручную
(инкогнито-браузер, нужный регион) и прислать тебе ссылки для обработки.
