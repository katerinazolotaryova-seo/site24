# Инструменты по блокам

Для каждого блока — что использовать без доступа клиента (публично/по своей
подписке) и что даёт доступ клиента, если он есть.

| Блок | Без доступа клиента | С доступом клиента |
|---|---|---|
| 1. Снимок vs конкуренты | Serpstat/Ahrefs/Semrush (своя подписка): позиции, Traffic Value, Share of Voice | GSC: точные клики/показы вместо оценки трафика |
| 2. Рынок и ниша | Ручной просмотр выдачи и сайтов конкурентов, Wayback Machine (история структуры) | — |
| 3. Технический аудит | Screaming Frog/Sitebulb, `site:` в Google, PageSpeed Insights, проверка robots.txt/sitemap.xml напрямую по URL | GSC: покрытие индекса, реальные ошибки сканирования, санкции |
| 4. Семантика | Wordstat/Google Keyword Planner/Ahrefs Keywords Explorer, ручной обход каталога сайта | Данные по фактическим запросам, приносящим трафик (GSC/GA4) |
| 5. AI-видимость | Ручные запросы в ChatGPT/Gemini/Perplexity/Google AI Mode по сценариям ниши | — |
| 6. Ссылочный профиль | Ahrefs/Semrush/Serpstat (своя подписка): бэклинки клиента и конкурентов | GSC → «Ссылки» как доп. сверка |
| 7. Приоритизация | Синтез блоков 1–6 | — |
| 8. Дорожная карта | Внутренний стандарт студии (6 направлений, помесячно) | Бюджет/сроки клиента уточняют реалистичность этапов |
| 9. Отчётность | Внутренний стандарт студии | На этапе ведения — GA4/GSC для наполнения отчётов |
| 10. Кейс и команда | Внутренние материалы site24 | — |
| 11. Цель в деньгах | Интервью с клиентом (числа со слов) | GA4/CRM для проверки текущих цифр конверсии |

## Сборка самой презентации

Финальную деку собирать `pptx`-скиллом, ориентируясь по вёрстке/структуре на
`SEO_Strategy_Bettertone_v3.pptx` из корня репозитория (слайд-мэппинг — в
`SKILL.md`). Не копировать текст/цифры чужого кейса — только структуру и стиль
подачи.
