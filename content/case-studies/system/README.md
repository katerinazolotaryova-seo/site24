# Система написання кейсів Site24

Процес, що перетворює **короткі наробки команди + результати** на готовий, узгоджений за структурою й тоном кейс по SEO/PPC — за допомогою агентів. За зразок узято мульти-агентний сетап Godex, адаптований під кейси Site24.

## Що тут лежить
| Файл | Призначення |
|------|-------------|
| `case-writing-guidelines.md` | **Ядро.** Структура кейса, tone of voice, подача метрик, ілюстрації, анонімізація, SEO-оформлення, фінальний чек-лист. Усі агенти звіряються з ним. |
| `intake-template.md` | Форма, яку заповнює команда (нотатки + результати). |
| `templates/` | **Шаблони кейсів «у вакуумі» (SEO).** Уніфікована канва під магазин і послуги + голосо-дружні опитувальники + промпт-компілятор. Швидкий шлях: ніша + цифри + скріни → готовий кейс. Деталі — `templates/README.md`. |
| `workflow.md` | Процес покроково: intake → райтер → 2 ревьювери → правки → дизайнер → фінал. |
| `agents/writer-seo.md` | Райтер SEO-кейсів. |
| `agents/writer-ppc.md` | Райтер PPC-кейсів. |
| `agents/reviewer-cmo.md` | Ревьювер очима персони CMO/маркдір серед. бізнесу. |
| `agents/reviewer-owner.md` | Ревьювер очима персони власника малого бізнесу. |
| `agents/designer.md` | Дизайнер-ілюстратор (HTML-графіки й схеми). |
| `drafts/` | Робочі чернетки кейсів та інтейки. |
| `illustrations/` | HTML-ілюстрації по слагу кейса. |

## Як почати (швидко)
1. Спеціаліст заповнює `intake-template.md` → кладе копію в `drafts/` як `YYYY-MM-DD-EN-<slug>-intake.md`.
2. У сесії просиш Claude взяти роль райтера (`agents/writer-seo.md` або `writer-ppc.md`) і написати чернетку.
3. Проганяєш обох ревьюверів, зводиш правки, райтер їх вносить.
4. Дизайнер робить ілюстрації.
5. Фінальний чек-лист з кінця гайдлайнів → передаєш у CMS.

Детально — у `workflow.md`.

## Принципи
- Агенти — **spec-документи**: Claude читає файл і бере роль (не Claude Code субагенти).
- Мова кейсів — **українська**. EN/RU — окремим треком пізніше.
- **Жодних вигаданих цифр** — лише дані з інтейку. Прогалини маркуються `[[уточнити: …]]`.
- Один словник секцій усюди — назви блоків лише з гайдлайнів.
