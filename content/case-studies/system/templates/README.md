# Шаблони кейсів «у вакуумі» (SEO)

Уніфікована канва SEO-кейсів по 2 напрямках. Скоуп робіт по SEO майже завжди однаковий — тож стандартний кейс уже написано прозою, а під конкретний проєкт лишилось вставити нішу, цифри й скріни. AI рерайтить канву щоразу по-новому, тож кейси не виходять клонами.

## Потік за 3 кроки

1. **Обери вертикаль → візьми шаблон**
   - Інтернет-магазин → [`seo-ecommerce-template.md`](seo-ecommerce-template.md)
   - Послуги (lead-gen) → [`seo-services-template.md`](seo-services-template.md)

2. **Зібери дані по проєкту через опитувальник** (техспец або PM; можна **голосом** → транскрипт)
   - Магазин → [`intake-ecommerce.md`](intake-ecommerce.md)
   - Послуги → [`intake-services.md`](intake-services.md)

3. **Скомпілюй у готовий кейс** через [`compile-prompt.md`](compile-prompt.md)
   - Встав промпт + шаблон + відповіді в чат → готовий унікальний кейс українською.
   - Потрібен інший варіант формулювань — запусти ще раз: цифри ті самі, текст новий.

## Що взяли в канву з аналізу конкурентів (SEO-кейси)
Поверх базової структури додано 4 прийоми, яких у нас не було: **дорожня карта по етапах/місяцях** (прозорість процесу), блок **«Стратегія та підхід» + аналіз конкурентів** (продає мислення), **UX/юзабіліті** як драйвер конверсії, **inline-коментар фахівця** «Коментар [роль]» (за зразком кейсу про чай). Деталі — в оновлених `../case-writing-guidelines.md` (таблиця A).

## Конвенції
- `{{...}}` — плейсхолдер даних (заповнюється з опитувальника).
- `[[уточнити: ...]]` — маркер відсутніх даних. **Цифри й факти не вигадуються** — лишається маркер, поки команда не добʼє.
- Рівень анонімізації за замовч. — **3** (ніша + метрики, без назви клієнта), поки клієнт письмово не погодив вище.
- Мова — **українська**. EN/RU — окремим треком локалізації.
