# Site24 — UI strings (крос-сторінкові рядки)

**Призначення:** усі повторювані рядки інтерфейсу — хедер, футер, форми, повідомлення, пагінація, cookie. Перекладаємо ОДИН раз, далі скрізь однаково.

**Формат:** UA → EN → RU. Якщо рядок ще не у фінальному UA — мітимо «⚠️ verify» (звіримо при екстракції з прев'ю).
