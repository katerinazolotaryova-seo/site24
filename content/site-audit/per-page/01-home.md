# Сторінка: ГОЛОВНА (`/`)

[← Index](../2026-04-30-EN-site24-review.md)

**Контекст сторінки:** головна — це сторінка агенції в цілому під бренд-запит. Людина почула про Site24 (рекомендація, конференція, виступ) і заходить, щоб зрозуміти "хто ці люди" і "що вони роблять". Це не SEO-ленд для холодного запиту. Тому воронка має йти `Хто і що → Як → Чому довіряти → Приклади → Ціни → Дія`, а не `Hero → Кейси з наскоку`.

## A. Воронка

**Поточна послідовність (24 блоки):**
```
Hero → Stats(86%/1000+/9р/30 ніш) → Послуги (SEO+PPC) → "Що отримаєте" + chart →
Логотипи → "Переваги" (5 рядків) → "Site24 у цифрах" (1000+/150+/155К) → Форма #1 →
Кейси (6) → SEO vs PPC (порівняльний) → "Рішення для будь-якої ніші" + карта →
"Гнучкість у підходах" → "Звітність без прихованих деталей" → Команда →
"Чому клієнт-сервіс найкращий" → Google Partner + 10K бонус → Відгуки →
Total visits chart → "Зростання прибутку" → Тарифи → Конференції (зламано) →
Інструменти → Форма #2 → Блог → FAQ → Футер
```

**Що працює:** правильно, що Послуги (SEO+PPC) одразу після Stats — людина за бренд-запитом за 2 скрола розуміє "хто" і "що". Команда з реальними фото на місці. "Звітність без прихованих деталей" з лід-магнітом "Отримати приклад звіту" — найкращий блок для CMO.

**Що ламає:**

1. **Два блоки "Чому обирають нас" з однаковим eyebrow (P0).** "Переваги роботи з Site24" (5 рядків) + "Чому наш клієнт-сервіс найкращий" (4 картки) — той самий смисл під двома соусами. Об'єднати в один блок з 4 пунктами: Прозорість + Підтримка + Експертність + ROI.

2. **Конференц-блок з 2016 року на 21-му скролі (P0).** Б'є по позиціонуванню "9 років постійного розвитку". Плюс баг — карусель показує один слайд двічі. Або наповнити свіжими (2024-2025), або забрати.

3. **Дві форми, перша до доказу (P1).** Форма #1 "Дізнайтеся вартість" на 5-му скролі — до показу команди, кейсів і відгуків. Для бренд-запиту трохи м'якше — людина може хотіти швидко спитати ціну. Але правильніше — забрати першу і лишити фінальну, бо зараз форма #1 розриває логічний ланцюг "хто/що → як → довіра".

4. **Hero дає тільки hard-CTA "Обговорити проект" (P1).** Для бренд-запиту це нормально — людина прийшла, щоб зв'язатись. Але доповнити м'яким лід-магнітом "Отримати приклад звіту" з блоку "Звітність" — щоб дати вибір тим, хто ще не готовий писати. На старій версії одразу після hero йшла форма "Замовте безкоштовну перевірку" — повністю прибрали.

5. **SEO vs PPC порівняльний дублює "Послуги" (P1).** Користувач вдруге читає, що таке SEO і PPC. Залишити короткий опис на головній, розгорнутий — на сервісних сторінках.

6. **Stats розбитий на два блоки (P1).** 86%/1000+/9р/30 ніш у блоці 2 і 1000+/150+/155К у блоці 7 — "1000+" дублюється. Об'єднати в один блок з усіма метриками.

**Запропонована послідовність (22 блоки — реорганізація без втрати інформації):**
```
ХТО
1.  Hero (УТП "9 років, SEO+PPC для МСБ" + hard-CTA "Обговорити проект")
2.  Партнерства (Google Partner + Clutch — фактичний стек)
3.  Stats консолідовані: 86% / 1000+ / 30 ніш / 9 років

ЩО
4.  Послуги SEO/PPC (короткий опис двох сервісів)
5.  "Що отримаєте" + chart (benefit map результатів)
6.  SEO vs PPC — "Що обрати? Порада від Site24"
7.  Рішення для ніші + карта міжнародного досвіду

ЯК
8.  Чому Site24 (4-5 пунктів: Прозорість + Експертність + Гнучкість + Клієнт-сервіс + ROI)
9.  Команда (реальні фото з підписами — перенести з Pro nas)

ДОВІРА
10. Логотипи клієнтів (lineup ~12 брендів)
11. Кейси з логотипами і метриками
    → CTA "Дивитись усі кейси" (deep-link на /cases)
12. ★ CTA-БАНЕР темно-синій
    "Готові обговорити проект з нашою командою?"
    → CTA "Обговорити проект" (скрол на #final-form)
13. Відгуки + 2-3 відеовідгуки (LeBoutique / Plastics / GigaKyiv)
14. Звітність без прихованих деталей + ілюстрація дашборду
    (Total visits + Зростання прибутку як чарти всередині блоку)
    → CTA "Отримати приклад звіту" (soft, лід-магніт)

РІШЕННЯ
15. Тарифи (з "Що входить" під ціну)
    → CTA "Замовити консультацію" під кожним тарифом
16. Бонус 10 000 грн для нових Google Ads
    → CTA "Активувати бонус" (скрол на #final-form)

ЕКСПЕРТИЗА
17. Виступи і експертиза (конференції 2024-2025 — оновити блок)

    → deep-link "Усі статті" на /blog

ЗНЯТТЯ ЗАПЕРЕЧЕНЬ

ДІЯ
```

**Що з чим об'єдналось:**
- 2 Stats-блоки (86%/1000+/9р/30 + 1000+/150+/155К) → 1 блок з 4 цифрами; PPC-метрики і 155К запитів — у сервісні сторінки
- "Переваги" + "Гнучкість підходів" + "Клієнт-сервіс" → 1 блок «Чому Site24»
- 2 графіки (Total visits + Зростання прибутку) → ілюстрації всередині блоку Звітність
- Google Partner + 10K бонус → розщеплено: Партнерства (блок 2) + окремий бонус-блок (16)
- Форма #1 (5-й скрол) — прибрана; Форма #2 стає єдиною фінальною

**Що додалось:**
- CTA-банер темно-синій після Кейсів — мід-page вихід для готових
- Команда (зараз тільки на Pro nas)
- Відеовідгуки (зараз тільки текстові)

Логіка послідовності для бренд-запиту: **хто** (Hero + Партнерства + Stats) → **що** (Послуги + benefit map + порівняння + ніші) → **як** (Чому Site24 + Команда) → **довіра** (Логотипи → Кейси → CTA-банер → Відгуки → Звітність) → **рішення** (Тарифи + бонус) → **експертиза** (Виступи + Інструменти + Блог) → **зняття заперечень** (FAQ) → **дія** (Форма).

**CTA-карта:** 3 hard-CTA на форму (Hero, CTA-банер після Кейсів, Тарифи + бонус), 1 soft-лід-магніт у нативному контексті (Звітність), 2 deep-links на внутрішні сторінки (Кейси → /cases, Блог → /blog).

**Дослідницька база послідовності** (повний документ з цитатами і застереженнями — у [scalable-exploring-moore.md](/Users/mac/.claude/plans/scalable-exploring-moore.md)). Опорні цифри:

- **Бренд-запит = Most Aware (Schwartz):** людина за запитом "Site24" не шукає продаж проблеми — їй треба підтвердження вибору і ціна. Тому послідовність відрізняється від cold-traffic ленду. [Schwartz Pyramid of Awareness](https://b-plannow.com/en/the-schwartz-pyramid-guide-to-the-5-levels-of-customer-awareness/)
- **Above-the-fold:** 57% уваги — над фолдом, 74% — на перших 2 екранах (NN/g 2018, 57 453 фіксації). Тому Hero + Партнерства мусять давати повну "візитку" одразу. [NN/g Scrolling and Attention](https://www.nngroup.com/articles/scrolling-and-attention-original-research/)
- **Тарифи на сторінці:** 54% B2B-покупців виключають вендора, у якого цін немає на сайті (#1 причина), 71% більш схильні купити при видимих цінах (TrustRadius 2024). На поточній головній блок цін після 19 інших — недосяжний. [TrustRadius B2B Buying Disconnect](https://solutions.trustradius.com/vendor-blog/tech-buyers-demand-honest-and-up-front-pricing-info/)
- **Кейси > відгуки:** case studies впливають на 73% B2B-рішень, читаються <60 сек — у пам'яті лишається тільки цифра. Тому метрики в картках і логотипи клієнтів обов'язкові. [Demand Gen Report Content Preferences](https://www.demandgenreport.com/industry-news/b2b-content-preferences-survey-buyers-want-short-visual-mobile-optimized-content/22396/)
- **Відеовідгуки:** 79% людей переконані купити після відеовідгуку, 9 з 10 довіряють клієнту більше ніж бренду (Wyzowl 2024). Аргумент для додавання 2-3 відео від LeBoutique / Plastics / GigaKyiv. [Wyzowl Video Marketing Statistics](https://wyzowl.com/video-marketing-statistics/)
- **Конкретика в Hero:** заголовки з числами і спеціалізацією конвертять на 36% краще за generic (Conductor). Аргумент для заміни "Допоможемо сайту бути в топі" на "9 років, 1000+ клієнтів, SEO+PPC для МСБ".
- **24 → 22 блоки:** Hick's Law + класичне дослідження Iyengar (24 види варення = 3% покупок, 6 видів = 30%, +10×). Тут не радикальне скорочення, а консолідація дублів (2 Stats → 1, 3 "Чому" блоки → 1, 2 графіки → ілюстрація, 2 форми → 1) + перерозподіл за логічними секціями. [Laws of UX — Hick's Law](https://lawsofux.com/hicks-law/)
- **B2B-buyer behaviour:** 67% надають перевагу rep-free досвіду, 92% починають із вже-обраним вендором (Gartner 2025-2026). Підтверджує всю brand-aware логіку. [Gartner B2B Buying Journey](https://www.gartner.com/en/sales/insights/b2b-buying-journey)

## C. Візуальні правки

1. **Конференц-блок: карусель показує один слайд двічі (P0).** Перевірити в браузері при кліку на стрілки. Якщо контенту нема — забрати блок.
2. **Банер "10 000 грн": фігура перекриває цифру (P0).** Розмістити цифру зліва, фігуру справа без перекриття.
3. **Фото власниці без підпису (P1).** Додати ім'я і посаду під фото в hero і в блоці "Що обрати? Порада від Site24": "Катерина Золотарьова, засновниця Site24".
4. **Картки кейсів без логотипа клієнта і метрик (P1).** Додати: логотип клієнта (де є дозвіл) + 1-2 ключові цифри ("+250% доходу", "Топ-10 за 6 міс"). Заразом замінити лейбл "Кейс" на тип — "Кейс SEO" / "Кейс PPC" / "Кейс SEO + PPC".
5. **Графік "ЗРОСТАННЯ 50%" без підмета (P1).** "Зростання" чого — трафіку, продажів, заявок? Додати конкретику.
6. **Графік Total visits розбиває скрол (P1).** Зменшити висоту до ~400px, зробити ілюстрацією поруч із текстом, а не окремим блоком на повну ширину.
7. **CTA-банер "Бажаєте отримати консультацію" занадто великий (P1).** Скоротити висоту вдвічі, прибрати декоративну ракету.
8. **Trust-бейджі розкидані по сторінці (P1).** Hero, "Партнер Google", Інструменти, футер. Консолідувати в один блок "Партнерства і рейтинги" одразу після hero (Google Partner + Clutch + IT Rating Ukraine + Meta Business Partner якщо є).
9. **Логотипи клієнтів без посилань на кейси (P2).** Зробити клікабельними — клік веде на відповідний кейс або відгук.
10. **Карта світу без підписів країн (P2).** Україна, Польща, США, Канада.
11. **Карусель відгуків без лічильника (P2).** Додати точки навігації або "1 з 6".
12. **Іконки соцмереж закріплені збоку на всій сторінці (P2).** Перевірити мобільну версію в Етапі 2.

## D. Блокові правки

### Додати

1. **Тарифи: під кожну ціну "Що входить" (5-7 пунктів) (P0).** Зараз 3 однакові картки без диференціації за $550 vs $750.
2. **FAQ: 3-4 питання про болі МСБ-власника (P1).** "Як ви гарантуєте результат?", "Що буде якщо результату не буде?", "Скільки коштуватиме після першого етапу?".
3. **2-3 відео-відгуки від найсильніших клієнтів (P1).** LeBoutique, Plastics, GigaKyiv.
4. **Згадка "український малий і середній бізнес" (P2).** У hero, Про нас, footer description (рек. #1 з конкурентного аналізу).
5. **Окремий блок про міжнародні проекти (P2).** Зараз тільки рядок у Stats — винести як міні-блок з прапорами 7 країн.

### Забрати

1. **Блок "Що обрати? Порада від Site24" (P1).** Дублює пояснення SEO vs PPC, та сама модель-фотографія.
2. **Stats розбитий на два блоки** (86%/1000+/9р/30 + 1000+/150+/155К) — об'єднати в **один блок з 4 опорними метриками**: 86% (повернення клієнтів — найсильніший trust-signal), 1000+ клієнтів, 30+ ніш, 9 років. PPC-метрики (150+ кампаній) і 155К запитів — перенести в сервісні сторінки SEO/PPC, де релевантніші. Hick's Law: менше цифр — глибше запам'ятовуються (P1).

### Спірне (підтвердити з власником)

1. **Pricing PPC від $550** — на старому сайті від $380 (+45%). Інтенційне? Якщо так — обґрунтувати у "Що входить".
2. **"Senior Project"** — обірвана посада Олександра. Project Manager? Senior Account?
3. **Бонус 10 000 грн для нових Google-акаунтів** — постійна пропозиція чи акція? Якщо постійна — окремий лід-магніт з власним CTA "Активувати бонус".
