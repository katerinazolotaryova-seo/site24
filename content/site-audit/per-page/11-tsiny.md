# Сторінка: ЦІНИ (`/czini-na-prosuvannya-ta-rozkrutku-sajtiv/`)

[← Index](../2026-04-30-EN-site24-review.md)

**Контекст сторінки:** інтенціональна сторінка для людини, яка вже вирішила цікавитися агенцією і хоче побачити **зведення цін на всі послуги в одному місці**. Найгарячіший етап воронки після Кейсів. Сторінка має дати: a) повну картину цін (SEO + PPC + SERM + сервісні), b) фактори формування ціни, c) калькулятор/форма для індивідуального прорахунку.

**Загальний діагноз:** сторінка структурно існує, але **показує тільки SEO-тарифи**. PPC, SERM, AI, інші послуги не представлені. Плюс **URL-slug "czini"** — нечитабельний транслітерат (має бути `tsiny` або `ciny`). SEO-фейл для агенції що продає SEO.

## A. Структура

**Поточна послідовність (~13 блоків):**
```
URL: /czini-na-prosuvannya-ta-rozkrutku-sajtiv/  ← SEO-фейл slug
↓
Hero "Вартість SEO просування та розкрутки сайтів" → 
4 SEO тарифи ($350/$550/$750/$950) + 2 додаткових (SEO аудит $280, Семантика $280) →
Чинники ціноутворення (5 блоків) → Досвід (Stats: 8 років) →
Логотипи → Вартість окремих послуг (6 сервісів) → Переваги компанії →
Відгуки → Команда → CTA форма → FAQ → Футер
```

**Що ламає:**

1. **URL slug "czini" замість "tsiny" або "ciny" (P0).** SEO-фейл. "czini" не читабельний транслітерат, ймовірно зроблено через автоматичну українську транслітерацію (cz=ц), але стандарт KMU 2010 каже "ts". Особливо боляче для **агенції, що продає SEO**. Виправити slug на `/tsiny/` або `/ciny/`, поставити 301 з поточного.

2. **На сторінці "Ціни" немає PPC тарифів (P0).** Користувач, що шукає "Site24 ціни" або "вартість Google Ads Site24", тут отримує тільки SEO. Має бути зведення:
   - SEO ($350-$950)
   - PPC ($270-$380 + аудит $95)
   - SERM ($250-$550)
   - SEO-аудит ($250-$480)
   - Семантика ($250-$480)
   - AI просування ($350-$750)
   - Закордонні (за домовленістю)

   Зараз — лише SEO + 2 додаткових. Розширити до повної картини.

3. **Тарифи $350/$550/$750/$950 розходяться з SEO-сторінкою $380/$580/$780 (P0).** На сторінці SEO три тарифи $380/$580/$780. Тут чотири $350/$550/$750/$950. Розходження і за кількістю, і за цифрами. Узгодити.

4. **"$950 SEO проєктування" — новий тариф (P1).** Не показаний на сторінці SEO. Якщо це окрема послуга (супровід розробки нового сайту) — додати на SEO або зробити окрему підсторінку.

5. **Stats "8 років досвіду" (P0).** Конфлікт чисел. Системно — див. [index](../2026-04-30-EN-site24-review.md).

6. **Без калькулятора (P0).** Сторінка "Ціни" без калькулятора — стандартний пробіл. Користувач хоче "ввести URL → отримати ціну". Зараз тільки форма "Отримати розрахунок", яка відкриває email-листування. Хоча б простий калькулятор: тип послуги → розмір сайту → орієнтовна вилка.

7. **Без порівняльної таблиці тарифів (P1).** 4 тарифи показано як 4 картки, але "що входить" в кожен — нема (системна проблема). Порівняльна таблиця "SEO просування / SEO розкрутка / SEO послуги / SEO проєктування" з рядками "Кількість ключів / Тексти / Лінкбілдинг / Тех. оптимізація / Звіти / Ціна" — стандартний патерн.

8. **Назви тарифів незрозумілі (P1).** "SEO просування" / "SEO розкрутка" / "SEO послуги" / "SEO проєктування" — синоніми, які звучать майже однаково. На SERM тарифи названі Start/Premium/Enterprise — кращий нейминг. На SEO тарифи теж незрозумілі. Уніфікувати: можна Start ($350) / Growth ($550) / Pro ($750) / Custom ($950+).

## C. Візуальні правки

1. **Тарифи без "Що входить" (P0).** Системно.
2. **Без калькулятора (P0).** Базовий калькулятор як патерн.
3. **Без порівняльної таблиці (P1).**
4. **Final CTA з ракетою (P1).** Системно.

## D. Структурні правки

### Перебудувати

1. **URL slug `/czini-...` → `/tsiny/` (P0).** SEO-критично.

### Додати

1. **PPC, SERM, AI, Семантика, SEO-аудит, Закордонні — повний прайс-лист (P0).** Сторінка "Ціни" має бути єдиним місцем для всіх цін. Якщо є окремі сторінки тарифів — лінкувати.
2. **Калькулятор (P0).** Простий: тип послуги + розмір сайту → вилка.
3. **Порівняльна таблиця тарифів (P1).**

### Уточнити з власницею

1. **Чому ціни розходяться?** Тут $350/$550/$750/$950 vs SEO $380/$580/$780 — інтенційно чи помилка? Узгодити цифри.
2. **"$950 SEO проєктування"** — нова окрема послуга чи варіант "великих проектів"? Чи треба окрема сторінка?
3. **PPC ціни на сторінці "Ціни"** — додавати?
