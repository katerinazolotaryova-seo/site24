# Сторінка: SEO-АУДИТ САЙТУ (`/tehnichnij-seo-audit-sajtu/`)

[← Index](../2026-04-30-EN-site24-review.md)

**Контекст сторінки:** разова послуга — детальний технічний SEO-аудит. Інтенціональний трафік: a) "у мене сайт, треба перевірити чи все ок з SEO" — теплий, разовий покупець, b) з SEO-сторінки як апсейл. Аналогічно до Аудиту PPC. Сторінка має продемонструвати глибину аудиту (що буде в звіті) і дати фіксовану ціну.

## A. Воронка

**Поточна послідовність (~17 блоків):**
```
Hero "Комплексний SEO-аудит сайту" → Переваги (3) →
Ознаки потреби перевірки (6) → Чому Site24 (6) → Що входить (6 розділів) →
Ключові результати (6) → Етапи проведення (6) → Інструменти (5) →
Відгуки → Тарифи (3 пакети $250/$380/$480) → Що впливає на ціну (6) →
Клієнт-сервіс (4) → Команда → Про компанію → FAQ (10) → Final CTA → Футер
```

**Що працює:** Структура чітка, типова для сервісної підсторінки. "Ознаки потреби перевірки (6)" — як на SERM "Сигнали негативу" — закриває біль "чи мені треба".

**Що ламає:**

1. **Stats: "14 років досвіду" (P0).** Як на SERM/Семантика. Конфлікт. Системно.

2. **Тарифи $250/$380/$480 — однакові з Семантикою (P1).** Дві різні разові послуги мають однакові цінові пакети. Може це фактично одна цінова сітка, але клієнту виглядає як копіпаст.

3. **На сторінці "Ціни" SEO-аудит "$280", тут $250/$380/$480 (P0).** Розходження. Як з Семантикою — узгодити.

4. **Hero без керівника (P0).** Системно. Євгеній (керівник SEO) має бути.

5. **Дублює структуру з Семантикою і Аудитом PPC (P1).** Hero / Stats / Що входить / Етапи / Тарифи / FAQ / Команда — однакова сітка. Якщо це підсторінки — можна спростити команду/Про компанію через посилання на /pro-nas/.

6. **Final CTA "Замовити консультацію" (P1).** Слабкий. Має бути "Замовити SEO-аудит" — конкретно про те, що сторінка пропонує.

## B. Текстові помилки

| Знайти | Замінити | Де | Пріоритет |
|---|---|---|---|
| 14 років досвіду | (узгоджена цифра) | Stats | P0 |
| $250/$380/$480 | (узгодити з $280 на сторінці Ціни) | Тарифи | P0 |
| Замовити консультацію | Замовити SEO-аудит | Final CTA | P1 |
| Системні | Див. [index](../2026-04-30-EN-site24-review.md) | Скрізь | P0 |

## C. Візуальні правки

1. **Hero: фото Євгенія (керівник SEO) + підпис (P0).** Системно.
2. **Тарифи без "Що входить" (P0).** Особливо критично — клієнт хоче бачити "сторінок звіту / годин консультації / до 100 URL / до 10000 URL".
3. **Картки кейсів немає взагалі — добре (плюс).** Аудит — разова послуга, кейси не потрібні. Хоча 1-2 "до/після" аудиту додали б довіри.
4. **Final CTA з ракетою (P1).** Системно.

## D. Структурні правки

### Додати

1. **Тарифи: "Що входить" (P0).** Глибина аудиту, обсяг звіту, кількість сторінок до перевірки, чи є презентація після, скільки годин консультації.
2. **Зразок звіту для скачування (P1).** "Подивіться як виглядає наш SEO-аудит" — посилання на анонімний приклад звіту PDF. Сильно знижує ризик для клієнта.

### Скоротити

1. **Команда / Про компанію — посилання на /pro-nas/ (P2).** Системно для сервісних підсторінок.

### Уточнити з власницею

1. **Тарифи $250/$380/$480 — як вибирати між пакетами?** Що саме входить у $250 vs $480 — глибина, кількість сторінок?
2. **Зразок звіту** — чи можна показати анонімний приклад для скачування?
