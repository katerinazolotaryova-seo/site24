# Сторінка: ПРОСУВАННЯ ЗАКОРДОННИХ САЙТІВ (`/prosuvannya-zarubizhnih-sajtiv/`)

[← Index](../2026-04-30-EN-site24-review.md)

**Контекст сторінки:** сервісна сторінка для українських компаній, які виходять на закордонні ринки (e-commerce, SaaS, послуги). Це "експортний" SEO — інтенціональний трафік: a) "ми відкриваємо філію у Польщі / Німеччині / США, треба SEO" — теплий, B2B власник МСБ із амбіціями експорту, b) холодний з пошуку "SEO США з України". На фоні війни — особливо актуальна тема для українських компаній, що шукають диверсифікацію ринків.

**Загальна оцінка:** структурно сторінка існує, але **вкрай поверхнева**. Тарифів немає (тільки "за домовленістю"), кейси без географічної прив'язки, FAQ — шаблонні з однаковими відповідями. Не позиціонується для української аудиторії — чому МСБ-власнику з України треба працювати з Site24 для США, а не з місцевою американською агенцією.

## A. Воронка

**Поточна послідовність (~10 блоків):**
```
Hero "Просування закордонних сайтів у топ Google" → Досвід міжнародний →
Порівняння міжнародного vs локального SEO → Переваги просування за кордон →
Проблеми, які вирішуємо → Послуги та етапи (6 кроків) → Логотипи →
Кейси (2 — без географії) → FAQ (10 — з ОДНАКОВИМИ відповідями!) →
Команда → Про компанію → Футер
```

**Що ламає:**

1. **FAQ — 10 питань з ОДНАКОВИМИ відповідями (P0).** Найгостріша помилка сторінки. Якщо WebFetch правильно прочитав — це шаблонний/lorem-ipsum заповнювач, який забули замінити справжнім контентом. **Або** заглушка для подальшого наповнення, **або** баг WP. Перевірити в браузері. Якщо реально однакові — переписати кожну відповідь індивідуально.

2. **Тарифів немає (P0).** "Вартість визначається щомісячно" — для української МСБ-аудиторії це вбиває довіру. Має бути хоча б вилка "від $X для початкових ринків (Польща, Чехія) / від $Y для США/Канади". Без цифр клієнт йде до конкурента.

3. **Кейси без географічної прив'язки (P0).** Показані ті самі 2 загальні кейси (PPC e-commerce + Studix.eu). Для сторінки про закордонні сайти потрібні конкретно: "Бренд X у Польщі за 6 міс зробили 50K MAU", "SaaS Y у США з топ-3 за ключі Z". Без таких кейсів сторінка не доводить компетенцію.

4. **"Українська компанія в США з України" — позиціонування відсутнє (P0).** Чому МСБ-власнику з України писати Site24 (Київ), а не місцевій агенції в США? Сторінка не дає відповіді. Можливі аргументи: a) ціна 30-50% дешевше за US-агенції, b) знання української специфіки SEO + західних практик, c) англомовний support, d) досвід з українськими брендами що йшли в експорт. Жодного з них на сторінці нема.

5. **Hero: "стокова ілюстрація групи людей" (P0).** Системно з SERM, AI, Семантика. Має бути керівник напрямку (хто веде закордонні проекти?) або реальне командне фото з блоку Pro nas.

6. **Stats — стандартні (8 років, 1000+ проектів) (P0).** Конфлікт чисел. Плюс для закордонної сторінки потрібні специфічні цифри: "З яких країн наші клієнти" (з конкурентного аналізу — Україна + 7 країн), "скільки міжнародних проектів" як підвид з 1000+.

7. **"продвижение" в URL російської версії (P1).** WebFetch згадав. Це системний баг локалізації — російська версія сайту має інший slug.

8. **Дублює структуру SEO/Семантика/Аудит (P1).** Шаблон сервісної сторінки + те ж саме Команда / Про компанію.

## C. Візуальні правки

1. **Hero: керівник напрямку або командне фото (P0).** Замість стокової ілюстрації.
2. **Прапори країн (P1).** Якщо клієнти з 7 країн (Україна + 6 закордонних) — показати прапори у Stats або окремим блоком "Ринки де ми працюємо".
3. **Картки кейсів з географічною прив'язкою (P0).** Бейдж країни + метрика.
4. **Тарифи відсутні візуально (P0).**
5. **Final CTA з ракетою (P1).** Системно.

## D. Структурні правки

### Перебудувати

1. **FAQ: справжній унікальний контент (P0).** Шаблонні відповіді — катастрофа для довіри.
2. **Hero: позиціонування для української аудиторії (P0).** "Виводимо українські бренди на ринки США / Європи" замість "Просуваємо сайти у ТОП-10 Google на ринках США, Канади та країн Європи". Перший варіант — наратив для МСБ-власника. Другий — sterile.

### Додати

1. **Тарифи з вилкою за регіонами (P0).** Польща/ЄС початкові — від $X. США/Канада — від $Y. Преміум-ринки — від $Z.
2. **Закордонні кейси з географією (P0).** 2-3 справжніх з прив'язкою.
3. **"Чому ми, а не місцева агенція" — окремий блок (P0).** 4-5 аргументів для українського МСБ.
4. **Прапори країн / карта (P1).**

### Уточнити з власницею

1. **Чи реально 10 FAQ мають однакові відповіді?** Перевірити в браузері. Якщо так — критично.
2. **Скільки реальних закордонних проектів?** І в яких країнах. Це база для кейсів.
3. **Хто веде закордонний напрям?** Має бути окремий фахівець або один з керівників.
4. **Тарифна модель** — чи можна публічно давати вилку, чи це конфіденційна частина для індивідуальних переговорів?
