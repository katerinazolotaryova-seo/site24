# Сторінка: ПРОСУВАННЯ В AI (`/ai-prosuvannya/`)

[← Index](../2026-04-30-EN-site24-review.md)

**Контекст сторінки:** **нова послуга 2025+** — просування в AI пошукових системах (ChatGPT search, Gemini, Copilot, Bing Chat). Це передова тема digital-маркетингу 2026. Інтенціональний трафік двох типів: a) "ми хочемо бути в ChatGPT" — теплий ранній клієнт (зазвичай маркетинг-директор у tech/SaaS), b) холодний з пошуку "AEO Україна" / "просування в ChatGPT" — дослідницький, ще не готовий замовляти. Сторінка має одночасно: a) пояснити що це таке (бо ринок ще нерозуміючий), b) показати що Site24 розуміється (експертний контент), c) дати конкретну дорожню карту.

**Загальна оцінка:** найсильніша з нових сторінок. Конкретні AI-цифри (1.4 млрд сесій ChatGPT, 49% зростання Q1 2025), згадка AEO як методології, диференціація від класичного SEO. Hero нормальний, але кейсів і досвіду в AI поки нема — це нормально для нової послуги, треба чесно позиціонувати.

## A. Воронка

**Поточна послідовність (~13 блоків):**
```
Hero "Просування в ChatGPT search та АІ пошуку" → Stats AI-тренду (4) →
Приклади результатів (скріншоти) → Обґрунтування (5 аргументів) →
Послуги (5 компонентів) → Етапи (7 кроків) →
Логотипи → Тарифи (Lite $350 / Mid $550 / Premium $750) →
KPI моніторингу (5 метрик) → Звітність → Відгуки (6) →
Про компанію + команда → FAQ (9) → Футер
```

**Що працює:**
- **AI-специфічні цифри в Stats** — "1.4 млрд ChatGPT сесій / 800 млн користувачів / 40%+ українців користуються щодня / 49% зростання Q1 2025". Це сильно. На фоні застарілих "8 років / 1000+ проектів" — тут видно що агенція слідкує за трендом.
- **Скріншоти "Приклади результатів"** — конкретні AI-видачі. Якщо це справжні приклади (а не маркетинг-мокапи) — сильний доказ.
- **AEO згадано** як методологія — використання правильної термінології.
- **7 етапів роботи** — деталізованіше за SEO/PPC, що для нової послуги виправдано.

**Що ламає:**

1. **Stats: "8 років на ринку" (P0).** Конфлікт чисел, як скрізь. На AI-сторінці "8 років" виглядає особливо дисонансно — нова послуга на старому досвіді. Або зменшити акцент на "роки", або позначити окремо "8 років SEO + 1 рік AEO-практики".

2. **Кейси AI-специфічні відсутні (P0).** Показані стандартні PPC/SEO кейси. На AI-сторінці критично потрібно одне з двох:
   - 2-3 справжніх AI-кейси ("Бренд X у ніші Y: за 4 місяці отримали 12 згадок в ChatGPT search для запитів Z")
   - **Чесна заява:** "AI-просування — нова послуга з Q4 2025. Поточних публічних AI-кейсів ще немає, але у нас є експертиза з технічного SEO + AEO + Bing-оптимізації, яку ми застосовуємо для перших клієнтів. Запит на ранній партнерство — нижче."

3. **Згадані тільки 4 AI-системи: ChatGPT, Gemini, Copilot, Bing Chat (P1).** Не згадані Perplexity (швидко зростаюча AI-search) і Claude. Якщо їх не оптимізують — позначити чому. Якщо технічно те ж саме — додати в список для повноти.

4. **Тарифи Lite/Mid/Premium $350/$550/$750 — копія SEO структури (P1).** На SEO такі ж пакети для нових/середніх/великих сайтів. Для AI-послуги вилка має бути іншою — тут не "розмір сайту" головна змінна, а "конкурентність ніші в AI" і "поточний рівень видимості". Подумати про іншу модель цін.

5. **9 FAQ, але без "коли реально побачу результат?" (P1).** Гарячий біль для AI-просування — невизначеність часу. Додати окремий FAQ.

6. **Hero CTA "Отримати консультацію" (P1).** Слабкий. Для нової послуги м'якший вхід "Безкоштовний AI-аудит видимості" — чи з'являється бренд у топ-3 ChatGPT search для ключових запитів. Це і trial-CTA, і впізнаваність експертизи.

## C. Візуальні правки

1. **Hero: підпис під фото керівника (P0).** Системно. WebFetch згадав "жінка в очках" — ймовірно Катерина (як на Контактах). Підпис.
2. **Скріншоти AI-видачі — перевірити чи реальні (P0).** Якщо це маркетинг-мокапи замість реальних — дуже ризик для довіри. Замінити на справжні (з анонімізацією бренду якщо треба).
3. **Тарифи без "Що входить" (P0).** Системно. Особливо для AI-послуги, де клієнт не розуміє чим Lite відрізняється від Premium.
4. **Final CTA з ракетою (P1).** Системно.

## D. Структурні правки

### Перебудувати

1. **Кейси: реальні AI або чесне зізнання (P0).** Див. A.2.

### Додати

1. **Hero: лід-магніт "Безкоштовний AI-аудит видимості" (P1).** Низький бар'єр — клієнт дізнається чи з'являється його бренд у ChatGPT search.
2. **Perplexity і Claude у списку AI-систем (P1).** Або пояснення чому не покривають.
3. **FAQ: "коли реально побачу результат?" (P1).** Конкретні часові горизонти.
4. **Програма ранніх партнерств (P1).** Якщо AI — нова послуга, "перші 5 клієнтів отримують X% знижку + персональний моніторинг" — патерн для розкрутки нової послуги.
