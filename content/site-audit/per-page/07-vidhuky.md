# Сторінка: ВІДГУКИ (`/all-testimonials/`)

[← Index](../2026-04-30-EN-site24-review.md)

**Контекст сторінки:** соц-доказ. Користувач приходить через "Контакти ▾ → Відгуки", через CTA "Всі відгуки" з SEO/PPC сторінок, або через бренд-запит "Site24 відгуки". Інтент — підтвердити "цій агенції довіряють реальні люди". Сторінка має максимально швидко: a) показати масштаб і різноманіття клієнтів, b) дати фільтрувати по типу послуги/ніші, c) опційно — відеовідгуки (індустріальний стандарт за конкурентним аналізом).

**Загальний діагноз:** як і Кейси — це WordPress blog template без власного hero. Всього 6 фіксованих текстових відгуків, без сегментації, без дат, без відеовідгуків, без бейджа типу послуги. Той самий sidebar "Пошук по блогу + форма" з Кейсів. Структурно сторінка не виконує ролі вітрини соц-доказу.

## A. Структура сторінки

**Поточна структура:**
```
URL: /all-testimonials/
↓
Header →
(БЕЗ hero!)
Grid карток (2 колонки, 6 шт) + сайдбар (Пошук по блогу + Форма "Отримати консультацію") →
Final CTA "Отримати консультацію" →
Футер
```

**Поточна картка відгуку:**
- Фото автора (кругле)
- Ім'я + посада/компанія
- Текст (обрізаний на 4-5 рядках з "...")
- CTA "Читати відгук"
- БЕЗ: дати, типу послуги (SEO/PPC), оцінки-зірочок, тривалості співпраці

**Що ламає:**

1. **Відсутній hero (P0).** Сторінка починається одразу з гріду карток, без заголовка "Відгуки клієнтів", без опису, без числа на кшталт "Понад 50 відгуків від реальних клієнтів". Користувач, що прийшов, не одразу розуміє де він і скільки тут контенту.

2. **Sidebar з блогом — "Пошук по блогу" + форма (P0).** Системно з Кейсами. Це блог-шаблон, не testimonials-template. На сторінці відгуків не місце пошуку блогу. Прибрати або замінити на коротку панель фільтрів.

3. **Тільки 6 відгуків без пагінації (P0).** Якщо це повний пул — 6 за 9-14 років роботи виглядає мало. Якщо є більше — підняти. Згідно WebFetch тих самих 6 з'являються на головній і SEO/PPC. Тобто це **той самий шорт-ліст по всьому сайту**, без розширеної бази.

4. **Без сегментації / фільтрів за типом послуги (P0).** Всі 6 — про SEO. Якщо є PPC або комбо клієнти — додати. Користувач, що прийшов з PPC сторінки, очікує побачити PPC-відгуки, а тут ніша і тип не вказано взагалі.

5. **Без дат і тривалості співпраці (P1).** "Анастасія: працюємо досить давно", "Юлія: 2,5 роки". У текстах є тривалість, але на превью картки нема дати початку чи "5+ років співпраці". Це сильний trust-сигнал, який зараз втрачено.

6. **Без відеовідгуків (P1).** Конкурентний аналіз рек. #8 — записати відеовідгуки від найсильніших клієнтів (LeBoutique, Plastics, GigaKyiv — всі 3 представлені на сторінці). Зараз тільки текст з фото.

7. **Без тегів-бейджів типу послуги на картці (P0).** Системно з Кейсами. Має бути: SEO / PPC / SERM / Аналітика / SEO+PPC.

8. **Русизми у відгуках (P1).** Системно з SEO-сторінкою — "продвіженцев" (Олексій Аронов), "Хлопці справжні професіонали" (Ілля Ковальов), "грунтовність" (Артем Білодід). Узгодити з авторами і переписати.

## C. Візуальні правки

1. **Додати hero (P0).** Принаймні: заголовок "Відгуки клієнтів" + підзаголовок з конкретикою ("За 9 років співпраці — реальні відгуки від МСБ і enterprise клієнтів") + 1-2 stat метрики (загальне число, кількість років співпраці у середньому).

2. **Картка відгуку: додати бейдж типу послуги + дату/тривалість співпраці (P0).** Зараз: фото + ім'я + текст + "Читати відгук". Має бути: фото + ім'я + посада/компанія + **бейдж SEO/PPC/SERM** + **тривалість співпраці** ("5 років") + текст + "Читати відгук".

3. **Грід full-width замість 2 колонки + сайдбар (P1).** Системно з Кейсами. Прибрати блог-сайдбар, full-width 3-колонний грід.

4. **Кругле фото автора зеленого кольору картка (P2).** Виглядає трохи дитяче для B2B. Або змінити на квадратне з закругленими кутами, або на стриманіший фон (білий/світло-сірий).

5. **Іконки соцмереж збоку (P2).** Системно.

## D. Структурні правки

### Перебудувати

1. **Перенести з WP пост-типу в окремий CPT "Testimonials" (P0).** Як з Кейсами — зробити окремий шаблон без блог-сайдбара, з фільтрами. URL `/testimonials/` або `/vidhuky/`.

### Додати

1. **Hero (P0).** Див. C.1.
2. **Фільтри: Все / SEO / PPC / SERM / Аналітика (P0).** Системно з Кейсами.
3. **Відеовідгуки 2-3 від найсильніших клієнтів (P1).** Конкурентний аналіз рек. #8. LeBoutique / Plastics / GigaKyiv — всі 3 представлені текстовими відгуками, конвертувати у відео.
4. **Бейдж типу послуги + тривалість співпраці на картці (P0).** Див. C.2.
5. **Розширити пул відгуків до 15-20+ (P1).** За 9-14 років роботи "1000+ проектів" повинно бути більше зведень для публікації. Узгодити з власницею.
6. **Кейсі-форму CTA внизу вітрини (P1).** Аналогічно з Кейсами — `Не знайшли відгук схожого бізнесу? Напишіть нам, поділимось анонімною статистикою`. Це м'який CTA для скептичних відвідувачів.

### Уточнити з власницею

1. **Скільки реально відгуків можна показати?** Зараз 6 по всьому сайту. Якщо є більше у скриньці пошти / Slack — узгодити публікацію з клієнтами.
2. **Які клієнти готові на відеовідгук?** LeBoutique, Plastics, GigaKyiv — кандидати з топ-листа.
3. **Чи показувати тип послуги** на превью відгуку (не всі клієнти готові розкривати "ми у них SEO/PPC замовляли"). Узгодити з кожним.
