# Сторінка: ЗБІР СЕМАНТИЧНОГО ЯДРА (`/zbir-semantychnogo-yadra/`)

[← Index](../2026-04-30-EN-site24-review.md)

**Контекст сторінки:** сервісна сторінка для специфічної разової послуги — збір і кластеризація семантичного ядра. Інтенціональний вузький трафік: a) "у мене є свій SEO-фахівець, потрібна тільки семантика" — теплий, готовий заплатити фіксовану суму, b) з SEO-сторінки як апсейл або міні-послуга. Сторінка має дати конкретний результат у форматі deliverable: "Excel-файл з 5000+ ключами, кластеризованих по сторінках".

## A. Воронка

**Поточна послідовність (~22 блоки!):**
```
Hero "Семантичне ядро для вашого сайту" (стокова дівчина, не Євгеній) →
4 stats (14 років / 1000+ / Будь-яка складність / Будь-яка мова) →
Опис послуги для різних ролей → Переваги (6) → Визначення поняття →
Сегменти клієнтів → AI Search блок → Процес збору →
Користь (10 аспектів) → Тарифи ($250/$380/$480) → Чинники ціни →
Логотипи → Кейси (8 — ті самі що на SEO) → Переваги Site24 →
Результати в деталях → Відгуки → Клієнт-сервіс → Звітність →
Контактна форма → Команда → FAQ (11 — найбільше на сайті) → Футер
```

**Що ламає:**

1. **Stats: "14 років досвіду" (P0).** Як на SERM, SEO-аудиті. Конфлікт з 8/9. Системно — див. [index](../2026-04-30-EN-site24-review.md).

2. **Hero: "молода жінка в окулярах" — не Євгеній (P1).** Євгеній — керівник SEO відділу, семантика його напрямок. Якщо сторінка про конкретну SEO-послугу — на hero має бути Євгеній. Зараз стокова дівчина.

3. **22 блоки — забагато (P1).** Серед них дублі: "Користь семантики" (10) + "Переваги" (6) + "Переваги Site24" — три блоки про "чому це треба і чому ми". Кейси (8) дублюють /tag/kejsi/ і SEO. "Клієнт-сервіс / Звітність / Команда / Про компанію" — те саме що на головній і інших сервісних. Скоротити до 10-12 блоків з фокусом на конкретику послуги.

4. **Тарифи $250/$380/$480 (P0).** Розходяться з SEO ($380/$580/$780), Цінами ($350-$950, але там Семантика "$280"), SEO-аудитом ($250/$380/$480 — однакові з Семантикою). Пять різних наборів цін на сайті — узгодити.

5. **На сторінці "Ціни" Семантика "$280", тут $250/$380/$480 (P0).** Розходження. Або тут вилка для різних розмірів, або помилка. Перевірити.

6. **Кейси 8 — ті самі з SEO/PPC сторінок (P1).** Системно — на сервісних сторінках показані одні й ті ж загальні кейси. Для Семантики потрібні специфічні кейси: "до Х ключів → після N ключів кластеризованих" або "ядро зібрали → приріст трафіку через 6 місяців".

7. **AI Search блок як окрема секція (P0, плюс).** Цікаво — згадка AI Search **тут** на семантиці, що перетинається зі сторінкою AI Promotion (`/ai-prosuvannya/`). Якщо це справді унікальна перевага — підкреслити: семантичне ядро з урахуванням AEO (Answer Engine Optimization). Якщо тільки для маркетингу — узгодити позиціонування з AI-сторінкою.

8. **11 FAQ — найбільше на сайті (P1).** Можна скоротити до 7-8 найгостріших або згрупувати у блоки (Що це / Скільки коштує / Скільки часу / Що отримаю на виході).

## C. Візуальні правки

1. **Hero: фото Євгенія + підпис (P0).** Системно.
2. **Тарифи без "Що входить" (P0).** Системно. Особливо для Семантики критично — клієнт хоче бачити "до 1000 ключів / до 5000 ключів / unlimited".
3. **Final CTA з ракетою (P1).** Системно.
4. **Кейси без логотипів і метрик (P1).** Системно.

## D. Структурні правки

### Скоротити

1. **22 блоки → 12-14 (P1).** Об'єднати: "Користь семантики" + "Переваги" + "Переваги Site24" → один блок. Кейси/Відгуки/Команда/Звітність — посилання на /pro-nas/ замість повного дублікату.

### Додати

1. **Тарифи: "Що входить" (P0).** Кількість ключів, мови, додаткові послуги (кластеризація / структура / ТЗ копірайтерам).
2. **Семантика-специфічні кейси (P1).** Або пояснити "наші Семантика-кейси входять у комплексні SEO-кейси".

### Уточнити з власницею

1. **AI Search блок** — чи дублюється з /ai-prosuvannya/? Чи це окрема перевага семантики?
2. **Тарифи $250/$380/$480 vs $280 на Цінах** — узгодити.
