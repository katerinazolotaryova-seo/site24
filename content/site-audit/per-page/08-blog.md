# Сторінка: БЛОГ (`/blog/`)

[← Index](../2026-04-30-EN-site24-review.md)

**Контекст сторінки:** контент-маркетинг сторінка. Користувач приходить через "Контакти ▾ → Блог", через "Топ статей" сайдбар на інших сторінках, або через органічний пошук на конкретні статті. Інтент — почитати експертний матеріал, пізнати глибше тему. Для агенції блог — інструмент SEO-просування власного сайту і доказ експертності. Має бути: чітка структура (категорії), регулярна публікація, фільтри по темах.

**Загальний діагноз:** блог структурно нормальний (hero є, грід карток, пагінація на 4 сторінки), але **частково перетинається зі сторінкою Кейсів**. Кейси на сайті фактично є блог-постами з тегом "#Кейси Site24" — їх видно і в блозі, і на /tag/kejsi/. Це структурний борг (див. також [pages/04-cases.md](04-cases.md)).

## A. Структура сторінки

**Поточна структура:**
```
URL: /blog/
↓
Hero "Блог Site 24 — Медіа про SEO, маркетинг і майбутнє" + опис →
2 теги "#Теми": #Кейси Site24, #Юзабіліті →
Grid карток (8 шт на сторінку) + сайдбар (Форма + Топ статей + Карусель відгуків) →
Пагінація (4 сторінки) →
Футер
```

**Поточна картка статті:** обкладинка / заголовок / дата / автор / тег (необов'язково).

З 8 статей **3 — це фактично кейси** (вже є на /tag/kejsi/). Тобто блог-стрічка змішує два типи контенту.

**Що ламає:**

1. **Блог змішує статті з кейсами (P0).** Системний борг бекенду. Кейси = блог-пости з тегом "#Кейси Site24". У результаті користувач бачить в стрічці блогу і "Аудит юзабіліті" (стаття), і "PPC для e-commerce" (кейс — той самий, що і в /tag/kejsi/). Розв'язання: винести кейси в окремий CPT (див. [pages/04-cases.md](04-cases.md)). Тоді блог буде чистий, кейси — окремо.

2. **Тільки 2 теги ("#Кейси Site24", "#Юзабіліті") (P1).** Для блогу про SEO/PPC/маркетинг 2 категорії — занадто бідно. Має бути: SEO / PPC / Аналітика / Юзабіліті / Лінкбілдинг / Кейси / AI-просування / Тренди — 7-8 категорій. Зараз вибірка тегів дуже випадкова.

3. **"Site 24" з пробілом у H1 hero (P1).** Заголовок hero — "Блог **Site 24**" з пробілом, а в логотипі і всюди — "Site24" злитно. Системна помилка брендингу. Виправити на "Site24".

4. **Sidebar з формою + Топ статей + каруселлю відгуків (P2).** Для блогу sidebar нормальний (на відміну від Кейсів і Відгуків де він зайвий). Але форма "Отримати консультацію" на сторінці блогу — push-патерн. Користувач прийшов читати, не замовляти. Можна замінити на "Підписатись на новини" — тематично доречніше.

5. **Свіжість публікацій: 1 за 2026, 3 за 2025, 2 за 2024, 2 за 2023+ (P1).** Це нормальна частота (~1 стаття/2 місяці), але треба підтвердити план публікацій далі. Власниця як основний автор (Катерина) — ок, але в команді є ще Денис, Євгеній — їх теж можна залучити для PPC і SEO-технічних тем.

6. **Без фільтрів за датою / автором / типом (P2).** Дрібниця для блогу з 32 статтями (8×4 сторінки), але якщо буде зростати — пагінація без фільтрів стане незручною.

**Переписати:**

- **Hero опис** "Медіа про SEO, маркетинг і майбутнє. Дослідження, кейси, аналітика, тенденції та натхнення" — нормально, але "натхнення" звучить дисонансно для B2B. Замінити на "Дослідження, кейси, аналітика і практичні гайди для маркетологів МСБ".

## C. Візуальні правки

1. **Hero блога — оформлення непогане (плюс).** Не чіпати, тільки виправити "Site 24" → "Site24".

2. **Картки кейсів і статей виглядають однаково на превью (P0).** Системно з Кейсами — без бейджа типу. Має бути візуальна різниця: статті — блакитний бейдж "Стаття", кейси — зелений бейдж "Кейс [SEO/PPC]".

3. **CTA "Залишити заявку" у формі sidebar (P2).** Замінити на тематичне: "Підписатись на оновлення" + поле email. Користувач блогу не готовий замовляти, але готовий підписатися.

4. **Сайдбар "Наші відгуки" — карусель (P2).** Дрібниця, але карусель з 6 відгуків займає висоту. Можна скоротити до 1 вибраного відгуку з посиланням "Всі відгуки".

## D. Структурні правки

### Перебудувати

1. **Винести кейси в окремий CPT, прибрати з блогу (P0).** Системна правка з [pages/04-cases.md](04-cases.md). Після цього блог буде чистий — тільки статті.

### Додати

1. **Категорії для блогу (P1).** SEO / PPC / Аналітика / Юзабіліті / Лінкбілдинг / Тренди / AI-просування — мінімум 5-7. Зараз 2.
2. **"Підписатись на оновлення" замість "Отримати консультацію" в sidebar (P2).** Тематично доречніше.
3. **Author bio внизу статті (P2).** Якщо це Катерина Золотарьова — коротка плашка "Засновниця Site24, 14 років у SEO". Це підкріплює експертність матеріалу.
4. **Tag cloud замість 2 хештегів (P1).** Якщо буде 7-8 категорій — показати їх на сторінці блогу одразу.

### Уточнити з власницею

1. **План публікацій на 2026.** Зараз ~1 стаття за 2 місяці. Підтримати темп чи збільшити?
2. **Авторство.** Лише Катерина чи залучати Дениса (PPC) і Євгенія (SEO) для тематичних статей?
3. **Чи планується конвертація блог-постів типу "PPC для e-commerce" в кейси після CPT-перенесення?** Чи лишити в обох місцях (з канонічним посиланням)?
