# Site24 — контент і верстка

Робочий репозиторій для контенту та верстки сайту [site24.com.ua](https://site24.com.ua/)
(агенція SEO/PPC/AI-просування, керівниця — Катерина Золотарьова).

## Як це працює

- Правила роботи, контекст компанії та обмеження — у [CLAUDE.md](CLAUDE.md). Читати перед
  початком роботи.
- Усе публікується на сайт вручну людиною, поза цим репозиторієм — тут лише чернетки й
  пропозиції.
- Сайт побудований на WordPress, кастомна тема `site24` (`wp-content/themes/site24`). Прямого
  доступу до файлів теми з цього репозиторію немає — верстка ведеться як пропозиції в
  [layout-proposals/](layout-proposals/), а не прямі правки продакшн-файлів.

## Структура

| Папка | Призначення |
|---|---|
| `content/pages/` | Тексти сторінок сайту |
| `content/blog/` | Статті блогу |
| `content/case-studies/` | Кейси клієнтів |
| `layout-proposals/` | Верстка як пропозиції (HTML/CSS-макети, специфікації) |
| `assets/` | Зображення й бренд-матеріали для контенту |
| `drafts/` | Чернетки в роботі |
| `logs/` | Логи сесій, реєстр рішень |
| `tracking/` | Контент-план, задачі |

## Правила для співавторів

1. `git pull` перед початком роботи.
2. Одна людина — один файл, щоб уникати конфліктів.
3. Комітити й пушити одразу після завершення шматка роботи.
4. Ніяких облікових даних, паролів чи FTP/DB-доступів у цьому репозиторії.
