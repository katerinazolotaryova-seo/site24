# 2026-08-22 — Тестовий прогін content-semantics-agent на site24.com.ua

## Контекст

Катерина попросила прогнати skill `content-semantics-agent` на власному сайті Site24
як тестовий кейс — щоб побачити результат і скоригувати сам skill. Робота велась через
зовнішній пайплайн `D:\Claude\Clients\site24-seo-pipeline\` (поза цим репозиторієм) —
там і лежать усі артефакти нижче.

## Що зроблено

1. Заскафолжено нового клієнта `site24` у пайплайні (`clients/site24/`).
2. Дані Google Search Console витягнуто через Chrome (browser fallback — OAuth API для
   цього клієнта не налаштований): 3 місяці, властивість `sc-domain:site24.com.ua`.
   Топ-250 запитів із 1000 і всі 107 сторінок → `clients/site24/data/gsc-export/2026-08-22/`.
3. Чорновий `config.yml` (content_pillars, ICP, money_pages, site_type, languages)
   складено з доказів і **підтверджено Катериною** в чаті:
   - 5 пілорів: SEO-просування, PPC/контекстна реклама, AI-просування, Ціни/вартість,
     Кейси/портфоліо (окремий пілар, підтверджено)
   - ICP: власники бізнесу/маркетинг-директори, Київ/Україна → міжнародний; сигнал
     "може бути трафік конкурентів" — залишено як відкрите питання, не фільтрується
   - money_pages: тільки `/kontakty/` — окремих сторінок замовлення нема, конверсія
     через кнопки замовлення + чат на кожній сторінці
   - site_type: **catalog** (кластер = сторінка послуги, не блог hub-and-spoke)
   - languages: **тільки RU** цього разу (UA — окремий повний прогін пізніше)
4. Повний прогін Фаз 0–6 (seo-cluster skill) по всіх 5 пілорах, RU:
   `clusters/ru-catalog-2026-08-22/cluster-plan.md` + `structure.md`, і датований
   батч у `BACKLOG.md` (13 ідей).

## Ключові знахідки

- **Аномалія цін RU/UA:** `/ru/czini-na-prosuvannya-ta-rozkrutku-sajtiv/` дає ~48%
  усіх показів сайту (296K з 613K, 3 міс) на позиції ~48. UA-версія тієї ж теми —
  лише 12.8K показів. Канібалізація підозрюється, але не підтверджена — треба
  Query×Page join (OAuth), якого зараз нема. Катерина про це не знала.
- Архітектура сайту (RU) вже майже ідеально відповідає кластерам — 12 із 13
  кластерів мають живу сторінку, що вже ранжується. Реальний важіль росту —
  не новий контент, а чому наявні сторінки сидять на позиціях 30–60 (технічні/
  авторитетні фактори — поза межами цього skill'а). Єдиний реальний "створити нову
  сторінку" кандидат — Amazon Ads (зараз лише блог-пост, не сервісна сторінка).
- **Обмеження інструментарію:** `WebSearch` у цій сесії — US-only, ~5–7 посилань з
  AI-サマарі, не верифікований топ-10 для google.com.ua. Жодного результату із
  site24.com.ua чи українських конкурентів. Через це жоден Phase 2 висновок не
  дотягнув до тіру `Confirmed` — все `Hypothesis`. Це найбільше, що варто виправити
  в skill перед бойовим використанням.
